# Rubric: academic (university report) / 大学レポート

Score each criterion 0-5. Max 40.

| # | Criterion | What a 5 looks like |
|---|---|---|
| 1 | Task fit / 課題適合 | Answers every part of the assignment; stays within scope and length limits |
| 2 | Thesis / 主張 | A clear claim or question stated early and answered at the end |
| 3 | Logic / 論理 | Each paragraph supports the claim; no leaps, no contradictions |
| 4 | Evidence / 根拠 | Claims backed by data, sources, or reasoning; not opinion alone |
| 5 | Citation / 引用 | Sources are real, consistently formatted, and every borrowed idea is attributed |
| 6 | Original analysis / 考察 | Goes beyond summary: compares, evaluates, or draws a non-obvious conclusion |
| 7 | Structure / 構成 | Introduction, body, conclusion; headings and flow aid the reader |
| 8 | Writing / 文章 | Precise, formal, concise; no filler, no unexplained terms, consistent style |

## Pass condition

PASS only if total >= 32, no criterion is below 3, and there is no blocking issue.

## Always blocking

- Part of the assignment is unanswered
- A fabricated or unverifiable citation
- Passages that look copied without attribution
- The conclusion does not follow from the body
