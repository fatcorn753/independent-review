# Rubric: technical (technical report) / 技術レポート

Score each criterion 0-5. Max 40.

| # | Criterion | What a 5 looks like |
|---|---|---|
| 1 | Purpose and audience / 目的と読み手 | States the problem, the audience, and the decision or action the report supports |
| 2 | Correctness / 正確性 | Technical statements are correct; terminology is used precisely |
| 3 | Reproducibility / 再現性 | Environment, versions, parameters, and steps are enough for a reader to repeat the work |
| 4 | Quantitative evidence / 定量的根拠 | Results have numbers, units, baselines, and noted uncertainty; claims match the data |
| 5 | Limitations / 限界 | Assumptions, constraints, failure cases, and untested areas are stated honestly |
| 6 | Conclusion and next steps / 結論と次の一手 | Findings lead to concrete, actionable recommendations |
| 7 | Structure / 構成 | Summary first; background, method, results, discussion; figures and tables are labeled and referenced |
| 8 | Writing / 文章 | Concise, unambiguous, consistent terms; no unexplained jargon for the stated audience |

## Pass condition

PASS only if total >= 32, no criterion is below 3, and there is no blocking issue.

## Always blocking

- A result that cannot be traced to a method or data
- A number without a unit or baseline where it is needed for the conclusion
- Steps that cannot be followed (missing versions, commands, or inputs)
- A conclusion stronger than the evidence supports
